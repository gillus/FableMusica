# FableMusica

**Suono** — uno strumento musicale visivo in un unico file HTML, senza librerie (canvas + Web Audio).

Apri `suono.html` nel browser e tocca per iniziare.

- Muovendo il mouse o il dito dipingi scie di particelle e suoni: la posizione orizzontale sceglie la nota, quella verticale il timbro.
- Le note sono sempre intonate su una scala a scelta: pentatonica, maggiore, minore, blues.
- **Rec** registra i gesti per un giro di loop e li ripete come voce, ognuna con il suo colore.
- Riverbero, eco sincronizzato al tempo e base ritmica opzionale con BPM regolabile.
- Tre palette che cambiano anche il carattere del suono: Kandinskij, Monet, Mondrian.
- Pulsante per salvare il disegno come immagine PNG.

Scorciatoie: `spazio` Rec · `1` `2` `3` palette · `R` ritmo · `C` pulisci · `S` salva.
